Alat dan Bahan

Peralatan yang digunakan untuk membuat kabel LAN

🔌 Kabel UTP

Digunakan sebagai media penghantar data antara dua perangkat komputer.

🔗 RJ45

Konektor yang dipasang pada ujung kabel UTP.

🛠️ Tang Crimping

Digunakan untuk memasang konektor RJ45.

📡 LAN Tester

Digunakan untuk mengecek kabel LAN.

Langkah-Langkah

Cara membuat dan menggunakan kabel LAN

01

Siapkan Kabel UTP

Siapkan kabel UTP sesuai panjang yang diperlukan.

02

Potong Kabel

Potong bagian luar kabel menggunakan tang crimping.

03

Susun Kabel

Susun kabel berdasarkan urutan warna yang benar.

04

Pasang RJ45

Masukkan kabel ke konektor RJ45 lalu crimping.

05

Test Kabel

Gunakan LAN tester untuk memastikan kabel bekerja.

06

Hubungkan Dua Laptop

Hubungkan kabel LAN ke kedua laptop.

07

Atur IP Address

Atur IP kedua laptop agar berada dalam jaringan yang sama.

08

Sharing File

Aktifkan file sharing untuk berbagi file.
